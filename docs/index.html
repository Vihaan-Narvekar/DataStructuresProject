    How it works

    1. Run the rally. At the first AVL imbalance, view the repair or step through it, then resume the replay.
    2. Predict and search for $107. Replay the same prices in a different order and compare the search counts and growth charts.
    3. Customize the prices or open rotation practice. Select a node to inspect it. Use arrow keys to navigate the tree and Shift + arrow keys to move a selected node in the comparison panels.
    BST ordering
    Smaller keys go left, and larger keys go right. Sorted insertions can form a chain with height n − 1 and a worst-case search of O(n).
    AVL balance
    The balance factor is left height minus right height. Rotations bring each node’s factor back within −1 to 1 while preserving in-order traversal. This keeps worst-case search O(log n).
    Measurements
    An empty tree has height −1. A leaf has height 0. Every visited node counts as one comparison, including a match.
