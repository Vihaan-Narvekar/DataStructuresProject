    How it works

    1. Insert prices into both trees. Start with prices in ascending order, then replay the same keys in a different order.
    2. Search for a price and count the nodes each tree visits. Try the deepest key of the ordinary BST or a price you have never inserted.
    3. Select nodes to see their balance factors. Use rotation practice to repair the AVL tree at the moment it became unbalanced.
    BST ordering
    Smaller keys go left, and larger keys go right. Sorted insertions can form a chain with height n − 1 and a worst-case search of O(n).
    AVL balance
    The balance factor is left height minus right height. Rotations bring each node’s factor back within −1 to 1 while preserving in-order traversal. This keeps worst-case search O(log n).
    Measurements
    An empty tree has height −1. A leaf has height 0. Every visited node counts as one comparison, including a match.
